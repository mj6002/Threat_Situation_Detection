# Datasets

Nothing is committed. Download locally under `data/raw/` and record the actual path or shared-drive location below.

| Threat class | Candidate datasets | Notes |
|---|---|---|
| Violence / abuse | RWF-2000, UCF-Crime (relevant classes), Hockey Fight | Public benchmarks with labels |
| Crowd / stampede | ShanghaiTech, UCF-QNRF, Violent Flows | Density and crowd-motion data |
| Harassment-risk | Our own consented staged clips | No public dataset labels harassment |

## Licence checklist (do this before using each dataset)

- [ ] Access conditions and licence read; academic use allowed
- [ ] Download size fits our disk / Colab limits
- [ ] Train / validation / test split decided and written down
- [ ] Scene-aware split, so clips from the same scene never appear in both train and test

## Staged clips
