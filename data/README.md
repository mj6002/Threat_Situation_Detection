# data/

Nothing in this folder is committed (see .gitignore). Download datasets locally and keep this layout:

```
data/
  raw/            # downloaded datasets (RWF-2000, UCF-Crime subset, ShanghaiTech, ...)
  staged/         # our own consented staged clips (never upload these anywhere public)
  processed/      # extracted clips, frames, features
```

See docs/DATASETS.md for sources and the licence checklist.
